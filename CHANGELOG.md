# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
where applicable.

## [Unreleased]

### Added
- `repoai/` — optional, offline-first AI assistant layer (stdlib only, no new
  dependencies). Adds local rule engine, offline knowledge base, error
  diagnosis, diagnostic-bundle generation, an optional telemetry collector, and
  an environment self-check (`doctor`).
- New subcommands: `repo ask`, `repo diagnose`, `repo doctor`, `repo explain`,
  `repo faq`, `repo models`, `repo ai-admin`.
- Documentation under `docs/` (`ai-user-guide.md`, `ai-quickref.md`,
  `ai-handbook.md`, `internal-fs-layout.md`) and `contrib/collector-deploy.md`.
- AI command man pages generated by `release/gen-ai-manpages.py`.

### Changed
- AI telemetry (`ai.telemetry.enabled`) now **defaults to off**. No usage data
  is collected or transmitted unless an operator explicitly configures an
  endpoint. Offline/isolated regions never transmit data.
- Contribution flow moved to GitHub pull requests (DCO sign-off) instead of the
  upstream Gerrit instance.

### Notes
- This is a fork of the Android `repo` tool. The original `repo` behaviour,
  output, and exit codes are preserved; the AI layer is strictly additive and
  can be disabled entirely with `ai.enabled=false`.
